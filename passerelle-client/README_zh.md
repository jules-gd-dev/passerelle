# Passerelle 客户端与守护程序 (Daemon)

Passerelle 是一款专为现代开发设计的高安全性、全开放源代码隧道转发与本地服务自动化检测体系。它可以迅速为你地城开发服务构筑零多余配置的极速安全桥梁，并由本地系统绝对捍卫认证自主权。

---

## 为何开源客户端代码能彻底确保系统安全与信任

公开 Passerelle 守护进程核心架构代码为所有开发者确立了无可质疑的算法纯净度与安全背书：
* **零知识本地校验机制**：所有的登录鉴权 PIN 代码全由本机本地进行衍生与严格比对审裁；云端的外部网关仅作为互不信用的 WebSocket 转发桥梁工作。若远端发起尝试携带非法 PIN 申请，本机的守护进程将在内网渗透前毫不犹豫当即掐断拒绝。
* **毫无后门潜入及系统操控代码**：代码向群众开通核查验证，底层仅严格允许对待侦测范围内合规发现的开发用 HTTP 调试端口实行数据包裹投运；杜绝任何 Shell 调用控制和敏感系统目录搜括逻辑。
* **网络无痕迹承诺与零绑架生态**：向外挥散的心跳侦查包及基础机器标贴毫无保留接受大众监查；随时支持透过终端切入私有自托管网关平台。

---

## 快速运行部署 & 实时交互管理主控屏幕 (`passerelle ui`)

### 1. 挂载安装 & 重启动系统
```bash
npm install -g @julesgd/passerelle
passerelle setup
```

### 2. Live 实时互动命令行监控屏 (Console)
随时希望零距离干预底层运转、洞明各个直挂端口通信以及果断切断违规接入，只需唤醒交互面板：
```bash
passerelle ui
```
连进该本地监视仪表幕帘后，你可通过热键执行下列瞬间响应：
* `[r]` **刷新派生鉴权 PIN 密钥**：立马淘汰注废早前的密码 PIN 并立刻签发崭新的登录凭据。
* `[s]` **拷贝登录主链接**：顺滑把带着签权短参的浏览器直连访问地址抓进操作系统共享内存剪贴板中。
* `[c]` / `[l]` **调看握手通信池与监听服务状态**：浏览检视为内网上行转发建立着的存续隧道总计和探查回来的各端口运转状况。
* `[h]` **开启公共演示遮蔽屏 (Privacy Mode)**：于集体开会和多人合署屏幕时隐去露骨的敏感验证字符串和可视化方整条框二重编码图形。
* `[k]` **断杀踢零全部外联通道**：毫无迟疑一口气向外部接入流下令割离清离现有全部会话层连接。
* `[p]` **强制回声自现宣贯向网关**：立即促发回敲通令再次跟云端中心网关通报宣贯机身心跳及映射地线（或用指令: `passerelle register`）。
* `[d]` **从操作板中安静剥离隐藏**：默默褪下仪表操盘大窗但在幕后把由 PM2 看管守押着的隧道任务留在远后继续工作。

## 指令中枢完全运用解析指引表

| :--- | :--- | :--- |

| `stop / restart`| 不需要添写 | 将身处于不见影暗面干事的持续化跑命核心按指令截留中止挥斩或进行重启刷干流程 |
| `status / json`| 不需要添写 | 获取一目了然且凝练清晰的生活健康度总览表或是供批量作业程序所偏向喜悦承受吃的直写层排式 JSON 源报单 |
| `link / qr` | 不需要添写 | 从幕屏直接吐让开阔顺溜的浏览器专链地址或在您掌面里拉列显影高清易扫好记的点格斑彩化图形防空伪证条幅码 |
| `register / sync`| 不需要添写 | 不惊扰正在干事的背景常驻生命即从壳外呼请让底板重新上楼面赴会告知名向公立通接中心宣告复至事实 |
| `config` | `<索引键> <期望赋值>` | 浏览当今激活履行的基础指引准则或强硬掉包易嫁接新配置如指定去住主服务器落款所址去名等（例如: `gateway_url`） |
| `credits` | 不需要添写 | 大致向外界汇报致哀感念创作领队的辛勤付给心力赞扬表露名誉铭鉴记录本以及其源起出逃基地库线地址 |
| `ui / attach` | 不需要添写 | 把操屏人直接沉底嵌入进翻涌火烫活现的动态化监听领航大视屏窗去一睹真机运行丰华 |
| `logs / help` | 不需要添写 | 随叫随机翻印涌发自后台深居浅出守御将干所日夕垂印堆塑积累起来的小时纪元短行字章或者启揭说明名声大传引向簿 |
